## Zepto E-commerce SQL Data Analyst Portfolio Project
This is a complete, real-world data analyst portfolio project based on an e-commerce inventory dataset scraped from Zepto — one of India’s fastest-growing quick-commerce startups. This project simulates real analyst workflows, from raw data exploration to business-focused data analysis.

📌 Project Overview

This project analyzes Zepto’s e-commerce inventory data using PostgreSQL to explore product pricing, stock availability, discounts, and potential revenue.

📊 Project Objectives

* Perform Exploratory Data Analysis (EDA).
* Clean data by handling invalid prices and converting paise to rupees.
* Analyze product categories, inventory, and discounts.
* Identify value-for-money products and generate business insights using SQL.

📁 Dataset

The dataset was sourced from Kaggle and contains product names, categories, MRP, discounted prices, available quantities, weights, and stock status.

🛠️ Tools Used

* PostgreSQL
* SQL
* pgAdmin 4
* Microsoft Excel

🔍 Key Analysis

* Top products by discount percentage.
* Out-of-stock products with high MRP.
* Potential revenue by category.
* Average discounts across categories.
* Price per gram and inventory weight analysis.

🚀 How to Run

1. Create a PostgreSQL database.
2. Create the zepto table using the provided SQL file.
3. Import the dataset into PostgreSQL.
4. Execute the SQL queries to explore the data and generate insights.
   
📈 Key Findings

* Identified top products offering the highest discounts.
* Analyzed product availability and out-of-stock items.
* Estimated potential revenue across product categories.
* Compared average discounts among categories.
* Evaluated value-for-money products using price per gram.
* Analyzed inventory weight and pricing inconsistencies.
